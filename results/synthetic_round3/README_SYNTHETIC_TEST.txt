Synthetic Round 3 Test
======================

This dataset is synthetic and derived from Round 1 / Round 2 real-event templates.

Use it for:
- pipeline testing
- code debugging
- stress testing
- checking the frozen hierarchical model behaves as expected

Do NOT use it as an independent validation dataset or report its score as
real-world/generalization accuracy.

Dataset:
- 50 synthetic events
- 10 NONE
- 10 ONE
- 10 TWO
- 10 RETURN
- 10 DISTURBANCE

Frozen hierarchical model synthetic-test accuracy:
1.000

Because the synthetic curves were generated from the same two rounds used to
build the model, this score is expected to be optimistic.
